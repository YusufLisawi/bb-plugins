# Rendering a storybook-stills film on the render farm (NOBODY CAME, 2026-10-31): what broke and the fixes

The farm (`remotion-render-farm` skill, `farm render <project> <Comp>`) renders in Chrome capture mode with `@remotion/web-renderer`. A stills film needed these changes (all in story-studio):

1. **Remotion 4.0.539 + `@remotion/web-renderer` 4.0.539, every `@remotion/*` the same version** (`farm doctor` checks). `farm init <project> --audio <Comp>=<path>/mix.wav` for every composition.
2. **The browser renderer cannot draw `<Audio>`** (error "<Html5Audio> is not supported in @remotion/web-renderer", which the farm's scan reports only as `Cannot read properties of null (reading 'set')`). `Stills` skips `<Audio>` when `useRemotionEnvironment().isClientSideRendering`; the farm muxes `mix.wav` itself. To see a hidden mount error, patch the built page's scan loop to throw `errors.error` (see the build in `~/.cache/bb-farm/builds/*/dist/assets/index-*.js`).
3. **"joined N frames, expected N+1"** = the video was one frame short: the farm muxes with `-shortest`, so the mix must be LONGER than the video. `stills_build.py` now makes `dur` a whole number of frames (`ceil(dur*30) == frames`), and the mix handed to the farm is padded (`apad=pad_dur=0.6`; `vertical/build.py` pads the extracted mix the same way).
4. **An SVG `<mask>` (e.g. `DashDraw`) drops the whole frame to the browser renderer's fallback mode, which cannot draw CSS `radial-gradient` backgrounds** (the island map's sea went black halfway through). Draw such things without masks (a row of dots, plain strokes), or draw gradients as SVG `<radialGradient>` inside the SVG. Check every card with a gradient background by scanning the master for black corners (`/tmp/cardscan.py` pattern: ffmpeg a frame every 0.5 s of each card segment, test the corner pixels).
5. **Do not ship the whole `public/` (11 GB) to the workers.** Build a slim folder of hard links (`cp -l`: the six parts' `*.jpg`, `mix.wav`, `stills.json`, plus `nc-layers`) and point `farm.json` `"public"` at it (git-ignored). Keep the six mixes padded there.
6. **Canvas 2-D scenes (the 2.5-D painted scenes), the device card and the hook cards render correctly in capture mode as they are** (canvases start at the page origin, everything is a pure function of time). three.js scenes were not used in the final films.
7. **QA the masters**: `scripts/qa.py <slug>` (copy / link the master to `out/<slug>.mp4`): format, loudness −14 ± 0.7 LUFS, black / freeze, speech; then look at 12 frames of each master, and the first 0.5 s of each hook.
