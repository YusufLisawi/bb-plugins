# Brief templates

Copy one, fill every field, send it to the art thread. Keep one item per line.

## Icon or item sheet (gambits, cards, abilities, currencies)

```
New icon batch for <project>. Same style as <reference sheets/paths>: <painted/flat>, thick dark
outline, soft top-left light, no text or letters, transparent background, <no frame | coloured
rounded-square frame per item>.
Save as <art/sheets/name.png>, grid <cols>x<rows>, equal square cells, in this order:
1 <id> "<Name>" – <visual idea that shows what it does>
2 ...
Reply with the saved path and the grid order.
```

## Board tiles, terrain or textures

```
<N> tiles for <project>, top-down, seamless edges <yes/no>, <size> px each, matching <reference>.
Each sits in a <frame colour/shape | edge-to-edge> square. Distinct base colours: <list>.
Save as <path>, one row of <N>, order: ...
```

## Sprites and animation frames

```
<Character/object> sprite sheet for <engine/game>, <view angle>, <frame size> px cells,
<frames> frames per row for: idle (<n>), walk (<n>), attack (<n>). Same silhouette and palette in
every frame, consistent ground line, transparent background, no motion blur.
Save as <path>; reply with the rows/frames layout.
```

## Character, boss or portrait set

```
<N> portraits for <roles>, bust framing, <style>, consistent lighting and line weight, each with
one readable signature trait: <id> – <who they are, key prop/colour>. Transparent background.
Grid <cols>x<rows> in this order: ... Save as <path>.
```

## Background or scene

```
Background for <screen>, <aspect/size>, <mood>, low detail behind UI areas (<where UI sits>),
palette <colours>, no characters, no text. Save as <path>. 2 variations if the mood is unclear.
```

## Logo concepts

```
<2-3> distinct logo concepts for <name>. For each: a lockup (mark + exact wordmark "<Name>")
and a standalone mark that reads at 32 px. Transparent background, works on <background colour>,
style <painted/flat/geometric>, colours <palette>. Concepts: 1 <idea>, 2 <idea>, 3 <idea>.
Save under <art/logo/> as NN-<slug>-{lockup,mark}.png. Do not replace any live logo.
```

## UI art (panels, buttons, badges, frames)

```
UI pieces for <screen>: <list with sizes>. 9-slice friendly where noted (keep corners and
edges uniform), <style>, transparent outside the shape. Save each as <path>.
```

## Marketing or store images

```
<N> store/ad images, <size/aspect>, showing <product moment>, real UI screenshots composited
by us later (leave space at <area>), brand palette <colours>, no fake text. Save under <path>.
```

## Redo request

```
Redo only these, everything else is approved: <id or cell numbers> – <what is wrong> → <what it
should be>. Match <approved file>. Save as <new path> (one row), same cell size.
```
