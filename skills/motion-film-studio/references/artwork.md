# Artwork: generated illustrations via a Codex `imagegen` thread

> [!IMPORTANT] Owner rules (October 2026, after the Pillow Tales campaign)
> - **Images are generated by Codex in a bb thread, with its `imagegen` skill.** You write the prompt and attach the reference images; Codex generates and saves the files.
> - **Never call an image or video generation API yourself**: no Higgsfield, OpenAI Images/Sora, Kling, fal, Replicate, Gemini, even when a key or credentials file is on the machine.
> - **No AI video clips unless the user asks for them.** Motion comes from the film's own code: camera moves, parallax, particles, puppet rigs, page turns.
> - **When a route fails or runs out, stop and ask the user** before switching to anything else (another provider, a paid service, dropping the art).

Many films need no generated art at all: kinetic type, product UI and code-drawn shapes carry them. Generate images only when the concept needs illustrated worlds, characters or props.

## 1. Plan the batch

Write one list per film before asking for anything:

| name | use | aspect | references | notes |
|---|---|---|---|---|
| `dad-dragon` | hero scene, full frame | 9:16 | plush mascot | the dad does a dragon roar, the girl giggles |
| `jar` | prop to animate | 2:3 cut-out | — | glass jar, empty |

- **Full-frame scenes:** 9:16 (vertical films), the subject leaving room at the top for the headline.
- **Cut-outs** (props and characters that you animate in code): ask for a **perfectly flat chroma-green (#00FF00) background**, the subject centred with margin and no green on it. Key it to alpha afterwards (below).
- **Line art** that draws itself (chalk, ink): ask for white lines on pure black, then screen-blend it in the film.
- **Consistency:** the same characters across shots need the earlier image as a reference ("the same father and daughter from the reference, years later"). A brand mascot gets its reference sheet every time.
- **Different people really are different:** vary age, gender and ethnicity explicitly, and check at thumbnail size.
- **Never** ask for text in an image. Every word on screen is code.

## 2. Hand it to Codex

One thread per batch, with an absolute output folder and the references attached:

```bash
cat > /tmp/art-<slug>.md <<'TXT'
Use your imagegen skill to make these images for a motion film. Save each final image as a PNG at exactly the path given (create the folder), then reply with the list of saved paths.

Shared style for every image: <one paragraph: medium, light, palette, mood, "no text, no letters, no logos">.

1. <abs path>/public/films/<slug>/art/dad-dragon.png (9:16) — <prompt>. Reference: plush-bear.png (keep this exact character).
2. <abs path>/public/films/<slug>/art/jar.png (2:3) — <prompt>. Isolated, centred, flat pure chroma green #00FF00 background, no shadow on the background.
…
Look at every result. Regenerate any image with wrong anatomy, text artefacts, an off-model mascot, or two "different" people who share a face.
TXT
bb thread spawn --parent-self --provider codex --title "Art · <slug>" \
  --prompt-file /tmp/art-<slug>.md \
  --image /abs/path/public/campaign-art/plush-bear.png --json     # one --image per reference
bb thread wait <thread-id> --timeout 30m
bb thread output <thread-id>
```

- Keep working on the script, voice and code while it runs; wait only when you need the files.
- Several films can share one thread (one numbered list), or run as parallel threads when the batches are independent.
- Codex may also leave the images in its own image output; the paths it reports back are the source of truth. If a file is missing, ask the same thread to save it to the path; don't regenerate it yourself.

## 3. Review and prepare

- **Open every image** (Read the PNG) before it goes in a film. Make a contact sheet for a batch: `artsheet.py out.jpg a.png b.png …` (Pillow Tales project). Send fixes back to the same Codex thread with `bb thread tell <id> --message-file …`.
- **Key a green-screen cut-out to alpha** locally, then crop to the subject: `g - max(r, b)` above a threshold is background; despill the edge pixels.
- Record each image in `films/<slug>/art.log.jsonl` (name, prompt, references, the Codex thread id) so the README can credit it.

## 4. Use it in the film

- Stills move with code: a slow camera (`Pic` zoom/pan), parallax layers, light, particles, rigged characters, page turns, masks that draw on. Nothing sits still (picture.md).
- Frame a scene inside a designed object (a page, a window, a lantern, a phone screen) rather than as flat wallpaper, and keep headlines on a legible band.
- **If the user asked for AI video clips:** the clip comes from the generation route the user approved. In the film, play it as a JPEG frame sequence picked from the film's own frame (`ClipFrames` in the Pillow Tales `brand/StoryKit.tsx`). A `<Video>` element plays 8× slow inside the 240 fps motion-blur master.
